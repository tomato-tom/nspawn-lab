# 実行ファイル

コンテナ操作
paw.sh:
```
network( action ...)
    case action ?
        create
            bridge_create bridge addr
        delete
            bridge_delete bridge
        attach
            bridge_attach bridge name
        detach
            bridge_detach bridge name
        show
            bridge_show bridge
        list
            bridge_list
        *
            show_help
case action ...
    create
        container_create name [options]
    delete
        container_delete name
    run
        container_start name [options]
    restart
        container_stop name
        container_start name
    stop
        container_stop name
    shell
        container_shell name command
    show
        container_status name
    list
        container_list
    net
        network [options]
    help
        show_help
```

net からブリッジ作成に飛ぶ

オプション
```
run <name> [options]

# network
--network default              # デフォルト、NATで外部通信
--network bridge [bridge_name] # ブリッジ接続のみ、その他は別途設定
--none                         # なし、完全カスタム設定

# port
--port <host-port>[:container-port]
# 例 --port 8080:80

# ホストのディレクトリをマウント
--bind <host-dir>[:container-dir]
# 例  --bind $(pwd):/app

リソース制限
--memory=4g --cpu=3

カスタム設定
--config custom.conf
```
