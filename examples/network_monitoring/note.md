# sFlow 実験環境
この環境は、「データプレーン（実際の通信）」と「マネジメントプレーン（監視・可視化）」を論理的に分離し、スイッチで発生したフロー情報をリアルタイムにグラフ化する一連のパイプラインを模擬しています。

## 構成

- br0
    - trixie-05: nfcapd
    - trixie-06: nfsen-ng
- br1
    - trixie-04: router
    - trixie-09: scapy

### ネットワークセグメント

*   br0 (Management Segment: 10.0.0.0/24)
    *   監視データの収集・転送・保存・表示を行うためのバックボーンネットワークです。
    *   sFlow データグラムやメトリクスはこのセグメント上を UDP や HTTP で流れます。
*   br1 (Client Segment: 10.0.1.0/24)
    *   実験用のトラフィックを生成し、スイッチを経由させるためのデータ用ネットワークです。
    *   ここを流れるパケットが `hsflowd` によってサンプリングの対象となります。

---

### 各コンテナの役割

#### A. データ生成・サンプリング層
*   trixie-09
    *   `iperf3` や `tcpreplay` を使用して、`br1` 上に負荷トラフィックを生成します。
    *   送信されたパケットは `trixie-04` router へ到達します。
*   trixie-04 (router & hsflowd)
    *   この環境の中心となる仮想ルーターです。
    *   通過するパケットを `hsflowd` がサンプリングし、sFlow データグラムとしてbr0のnfcapdに向けてエクスポートします。

#### B. データ収集・処理層 (Pipeline)
*   trixie-05 (nfcapd)
    *   `br0` 上で待ち受け、`trixie-04` から送信されてくる sFlow データグラムを受信します。
    *   バイナリ形式の sFlow パケットを解析
*   trixie-06 (nfsen-ng)
