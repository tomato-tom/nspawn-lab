# 実行ファイル

コンテナ操作
paw.sh:
```
network( action ...)
    case action ?
        create
            bridge_create bridge addr
        delete
            bridge_delete bridge
        attach
            bridge_attach bridge name
        detach
            bridge_detach bridge name
        show
            bridge_show bridge
        list
            bridge_list
        *
            show_help
case action ...
    create
        container_create name
    delete
        container_delete name
    run
        container_start name
        network setup ??
    restart
        container_stop name
        container_start name
    stop
        container_stop name
    shell
        container_shell name command
    show
        container_status name
    list
        container_list
    net
        network @
    help
        show_help
```

net からブリッジ作成に飛ぶ
